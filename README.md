# eSIM Market UI

`esim-market-ui` is the frontend application for the **eSIM Market** project.

The application provides the user interface for interacting with eSIM Market services and communicates with the backend APIs exposed by the `esim-market-backend` repository.

## Technology

The UI is developed using React.

## Development

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

## Related Repositories

- `esim-market` — integration and local orchestration
- `esim-market-backend` — backend APIs and background services
